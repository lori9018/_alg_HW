# 迭代法入門範例：牛頓法求平方根

## 什麼是迭代法？

**迭代法（Iterative Method）** 是一種「先猜一個答案，再不斷用同一個規則修正它，直到夠接近正確答案」的方法。

整個流程只有四步：

1. **初始值**：先隨便猜一個答案 `x₀`
2. **迭代公式**：用規則由 `xₙ` 算出更好的 `xₙ₊₁`
3. **停止條件**：當誤差夠小（收斂）或次數太多時停止
4. **重複**：沒停就回到第 2 步

```
初始猜測 → 套用公式 → 更接近答案 → 夠接近了嗎？ ─是→ 結束
              ↑                          │否
              └──────────────────────────┘
```

> 生活比喻：猜數字遊戲。每次猜完，對方說「太大」或「太小」，你就依此調整，越猜越準。

## 範例問題：求 √a

我們要找 `x` 使得 `x² = a`。

### 迭代公式（牛頓法）

```
x_next = (x + a / x) / 2
```

**為什麼有效？** 若 `x` 太大，則 `a / x` 會偏小；若 `x` 太小，則 `a / x` 會偏大。
兩者取平均，就會更靠近真正的 √a。

### 以 √2 為例（初始猜測 x = 1）

| 次數 | x | 誤差 |
|-----|---|------|
| 1 | 1.500000000000 | 2.5e-01 |
| 2 | 1.416666666667 | 6.9e-03 |
| 3 | 1.414215686275 | 6.0e-06 |
| 4 | 1.414213562375 | 4.5e-12 |
| 5 | 1.414213562373 | 4.4e-16 |

只要 5 次迭代就和真實值 `1.41421356237...` 完全吻合。注意誤差下降得非常快，約每次有效位數**加倍**（這稱為「二次收斂」）。

## 執行方式

需要 Python 3（不需安裝任何套件）：

```bash
python newton_sqrt.py
```

想算別的數字，修改程式最下方的 `newton_sqrt(2)` 即可，例如 `newton_sqrt(10)`。

## 程式結構對應

| 概念 | 程式中的位置 |
|------|-------------|
| 初始值 | `x = a / 2 if a > 1 else 1.0` |
| 迭代公式 | `x_next = (x + a / x) / 2` |
| 停止條件（收斂） | `abs(x_next - x) < tolerance` |
| 停止條件（保險） | `for i in range(1, max_iter + 1)` |
| 更新後繼續 | `x = x_next` |

## 重點觀念整理

- **收斂（Convergence）**：結果越來越接近固定值。
- **容許誤差（tolerance）**：差距小於這個值就視為「夠準了」。
- **最大迭代次數（max_iter）**：避免公式不收斂時變成無窮迴圈。
- **初始值會影響速度**：離答案越近，收斂越快；有些方法初始值太差甚至會發散。

## 練習題

1. 把初始值改成 `100`，觀察需要幾次才收斂。
2. 把 `tolerance` 改成 `1e-3` 和 `1e-15`，比較結果與次數。
3. 修改公式為 `x_next = x + 1`，觀察會發生什麼事（提示：不收斂，靠 `max_iter` 保護）。
4. 進階：改寫成**二分法（Bisection）**求平方根，比較兩者收斂速度。

## 延伸：迭代法還用在哪？

- 梯度下降（Gradient Descent）：機器學習訓練模型
- 解線性方程組：Jacobi、Gauss-Seidel 法
- PageRank：搜尋引擎網頁排名
- 數值分析：求根、積分、微分方程
