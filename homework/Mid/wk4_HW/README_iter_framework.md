# 統一迭代框架：用同一個函數實作 9 種經典迭代演算法

`iter_framework.py` 的核心想法只有一個：

> **幾乎所有迭代法，都是「狀態 → 下一個狀態」的重複套用，直到收斂。**

程式先寫出一個通用的迭代骨架 `generic_iterator`，再用 9 個範例證明：不管是求根、解方程組、求特徵值、解微分方程，還是機器學習的 K-Means、EM，都只需要換掉「**狀態是什麼**」、「**怎麼前進**」、「**何時停止**」這三件事。

---

## 1. 環境與執行

- Python 3
- NumPy（`pip install numpy`）

```bash
python iter_framework.py
```

## 2. 核心：`generic_iterator`

```python
def generic_iterator(transition_func, is_converged, initial_state, max_iter=1000):
    state = initial_state
    for iteration in range(max_iter):
        next_state = transition_func(state)
        if is_converged(state, next_state, iteration):
            return next_state, iteration + 1
        state = next_state
    print("[警告] 達到最大迭代次數仍未完全收斂")
    return state, max_iter
```

| 參數 | 意義 | 數學對應 |
|------|------|----------|
| `initial_state` | 初始狀態（純量、向量、矩陣、Tuple 都可以） | x₀ |
| `transition_func` | 狀態推進函數 | xₖ₊₁ = g(xₖ) |
| `is_converged` | 收斂判定，拿到「舊狀態、新狀態、第幾次」 | ‖xₖ₊₁ − xₖ‖ < ε |
| `max_iter` | 安全上限，避免不收斂時無窮迴圈 | — |

**回傳值**：`(最終狀態, 實際迭代次數)`。

### 流程圖

```
initial_state ──► transition_func ──► next_state ──► is_converged?
                        ▲                                │ 否
                        └────────── state = next_state ◄─┘
                                                         │ 是
                                                         ▼
                                              回傳 next_state, 次數
```

### 設計重點

- **狀態是通用的**：因為框架完全不碰狀態的內容，所以它可以是數字（牛頓法）、向量（高斯-賽得爾）、矩陣（QR 演算法）、`(t, y)` 組合（RK4）、中心點陣列（K-Means）等。
- **用函數當參數**：`transition_func` 與 `is_converged` 都是 callable，範例大量使用 `lambda`，讓每個演算法只需寫幾行。

## 4. 各範例詳解

### 4.1 不動點迭代（Fixed-Point Iteration）

**問題**：找到 x 使得 `x = g(x)`。這裡 g(x) = Ax + c，其中

```
A = [[0.5, -0.2],     c = [0.3,
     [0.2,  0.5]]          0.4]
```

**為什麼會收斂？** 若 g 是「壓縮映射」（A 的譜半徑 < 1），不管從哪出發都會收斂到唯一不動點。此處 A 的特徵值模長為 √0.29 ≈ 0.54 < 1，所以收斂。

**驗證**：解 (I − A)x = c 得 x = [0.07/0.29, 0.26/0.29] ≈ [0.2414, 0.8966]，與程式輸出一致。

### 4.2 牛頓法（Newton's Method）

**問題**：解 `x² − 4 = 0`，從 x₀ = 1 出發。

**公式**：`x ← x − f(x)/f′(x)`，也就是用切線與 x 軸的交點當作下一個猜測。

**特性**：接近根時為「二次收斂」，有效位數大約每步加倍，所以只要 5 次就到達 2.000000。缺點是 f′(x) = 0 時會出問題，且初始值太差可能發散。

### 4.3 高斯-賽得爾法（Gauss-Seidel）

**問題**：解線性方程組 `Ax = b`，

```
A = [[ 4, -1,  0],    b = [ 7,
     [-1,  4, -1],          2,
     [ 0, -1,  4]]         13]
```

**公式**：第 i 個分量

```
xᵢ ← ( bᵢ − Σ_{j≠i} Aᵢⱼ xⱼ ) / Aᵢᵢ
```

**與 Jacobi 法的差別**：程式中 `x_new` 在迴圈內即時被更新，算 `x_new[i]` 時用到的 `x_new[j]`（j < i）已經是**新值**。這正是 Gauss-Seidel 通常比 Jacobi 收斂更快的原因。

**收斂保證**：A 為嚴格對角優勢矩陣（對角線元素大於同列其他元素絕對值總和）。解答為 `[2.25, 2, 3.75]`。

### 4.3 冪次迭代（Power Iteration）

**問題**：求矩陣 A 的**最大特徵值**與對應特徵向量。

**做法**：反覆把向量乘上 A 再正規化。直覺上，A 會把向量越來越拉向「最大特徵值」的方向。最後以 Rayleigh 商 `vᵀAv` 估計特徵值。

**限制**：收斂速度取決於第二大與最大特徵值的比值 |λ₂/λ₁|，比值越接近 1 越慢。

### 4.5 QR 演算法（QR Algorithm）

**問題**：一次求出矩陣的**所有特徵值**。

**做法**：每輪做 QR 分解 `Aₖ = QR`，然後反過來相乘 `Aₖ₊₁ = RQ`。因為 `RQ = QᵀAₖQ`（相似變換），特徵值不變，而矩陣會逐漸趨近上三角（對稱矩陣則趨近對角矩陣），**對角線上就是特徵值**。

程式中 `np.dot(*reversed(np.linalg.qr(Ak)))` 即是 `R @ Q`（`reversed` 把 `(Q, R)` 反轉成 `(R, Q)`）。收斂判定是檢查「非對角元素」的絕對值總和。

**驗證**：輸出 `[5.732, 2.268, 1.0]`，總和為 9，等於 A 的 trace（4 + 2 + 3）。

### 4.6 龍格-庫塔法 RK4

**問題**：解常微分方程 `dy/dt = y − t + 1`，`y(0) = 1`，在 [0, 2] 以步長 h = 0.2 前進。

**公式**：計算四個斜率 k₁~k₄，加權平均後前進：

```
yₙ₊₁ = yₙ + (h/6)(k₁ + 2k₂ + 2k₃ + k₄)
```

**這個範例的特別之處**：狀態是 `(t, y)` 的 Tuple，而且「收斂」並不是誤差變小，而是「時間走到終點」。這說明框架中的 `is_converged` 其實是通用的**終止條件**。

**驗證**：此方程的精確解為 `y = t + eᵗ`，在 t = 2 時為 9.389056，RK4 的 9.388889 非常接近。

### 4.7 PageRank

**問題**：計算網頁的重要性。把網路看成「隨機衝浪者」，沿著連結隨機跳轉，長期停留在各頁面的機率就是權重。

**做法**：建立 Google 矩陣 `G = d·M + (1−d)/n · 𝟙`（阻尼係數 d = 0.85，表示 15% 機率隨機跳到任意頁），然後對機率向量反覆做 `r ← G r`。這本質上就是**不做正規化的冪次迭代**（因為 G 是列和為 1 的隨機矩陣，向量總和保持為 1）。

**輸出**：`[0.3246, 0.2251, 0.2251, 0.2251]`，網頁 1 因為被最多連結指向，權重最高。

### 4.8 K-Means 聚類

**問題**：把資料分成 k 群。

**每輪兩步**（都包在 `transition` 裡）：
1. **分配**：每個點歸給最近的中心
2. **更新**：每群的中心改為該群的平均值

**狀態**是「中心點矩陣」，標籤只是中間產物。資料用兩團高斯分布（中心約 (2, 2) 與 (−2, −2)）產生，結果中心約為 `(1.83, 1.80)` 與 `(−2.11, −2.13)`。

### 4.9 EM 演算法（雙硬幣問題）

**問題**：有 A、B 兩枚硬幣，每次實驗（共 5 次，各擲 10 次）隨機選一枚擲，但**我們不知道選了哪一枚**（潛在變數）。要估計兩枚硬幣的正面機率 θ_A、θ_B。

**每輪兩步**：
- **E-step**：用目前的 θ，算每次實驗來自 A 的機率 `p_A = L_A / (L_A + L_B)`，並據此加權累計「期望的正反面次數」
- **M-step**：θ = 期望正面次數 / 期望總次數

**與 K-Means 的關係**：K-Means 是「硬分配」版本（每個點只屬於一群），EM 是「軟分配」版本（以機率分配）。程式註解中把 K-Means 稱為 Hard EM，就是這個意思。

## 6. 如何加入自己的迭代法

只要回答三個問題，就能套進框架：

1. **狀態是什麼？** → `initial_state`
2. **如何由這一步得到下一步？** → `transition_func`
3. **什麼時候停？** → `is_converged`

範例：用不動點迭代解 `x = cos(x)`

```python
import math

result, iters = generic_iterator(
    transition_func=lambda x: math.cos(x),
    is_converged=lambda old, new, i: abs(new - old) < 1e-8,
    initial_state=1.0,
)
print(result, iters)   # ≈ 0.739085
```

## 7. 觀念整理與注意事項

| 概念 | 說明 |
|------|------|
| 收斂（Convergence） | 狀態越來越接近固定值 |
| 收斂速度 | 牛頓法為二次收斂；不動點、高斯-賽得爾、冪次迭代為線性收斂 |
| 容許誤差 ε | 程式中皆用 1e-6，越小越準但需要越多次迭代 |
| `max_iter` | 保險機制，無法收斂時避免無窮迴圈 |
| 初始值的影響 | 牛頓法、K-Means、EM 都對初始值敏感，可能收斂到局部解甚至發散 |

**程式中值得留意的簡化**：

- 範例 8 直接取前 k 個資料點當初始中心，實務上常用 K-Means++ 以避免初始值不佳。
- 範例 9 計算似然時省略了二項係數，因為它在 A、B 相除時會抵消，不影響結果。
- 範例 4 標題寫「SVD」，實際上是用冪次迭代求主特徵向量；SVD 的奇異值與 AᵀA 的特徵值有關，因此兩者相關，但此範例並未完整做 SVD。
- 範例 6 的「收斂」其實是「終止條件」，因為 RK4 的步數本來就是預先決定的。
